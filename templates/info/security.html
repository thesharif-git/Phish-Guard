Our Security Controls

Encryption in Transit

All data transmitted between your browser and PhishGuard is encrypted using TLS 1.3. HTTP connections are automatically redirected to HTTPS.

Encryption at Rest

Stored scan data and user records are encrypted at rest using AES-256. Passwords are hashed using bcrypt with a unique per-user salt.

CSRF Protection

All state-changing requests require CSRF tokens. Session cookies are marked HttpOnly and Secure to prevent client-side access.

Access Controls

Role-based access control limits who can view raw scan data internally. We log all administrative access for audit purposes.

Infrastructure Security

  • Hosted on SOC-2 Type II certified cloud infrastructure.
  • Network segmentation isolates the database from public-facing services.
  • Automated dependency vulnerability scanning on every deployment.
  • Automated backups with encrypted offsite storage, tested monthly.
  • Rate limiting and abuse detection on all API endpoints.

Operational Practices

  • Security reviews on every significant feature release.
  • Annual penetration testing by an independent third party.
  • Incident response plan with defined SLAs for notification.
  • All team members receive security awareness training quarterly.

Responsible Disclosure

Found a security vulnerability in PhishGuard? We appreciate responsible disclosure. Please email us at security@phishguard.io with details. We aim to acknowledge reports within 48 hours and resolve critical issues within 7 days.

Please do not publicly disclose vulnerabilities until we have had reasonable time to address them. We do not pursue legal action against good-faith security researchers.

PGP key available on request.

Compliance

PhishGuard is aligned with SOC 2 Type II practices. We are GDPR-compliant for EU users and California Consumer Privacy Act (CCPA) compliant for California residents. See our Privacy Policy for data rights information.
